# Reloj Premium

App Android de reloj digital creada con Python + Kivy.

## Compilar

Subí esta carpeta a un repositorio de GitHub. Luego abrí **Actions** y ejecutá **Build Android APK**. Al terminar, descargá el artefacto **Reloj-Premium-debug** y dentro estará el APK.

El APK debug es para pruebas. Para Google Play habrá que crear una compilación release firmada y preparar icono, splash y metadatos.
